# Контекст и управление выполнением

Пакет `context` — стандартный способ **управлять жизненным циклом** работы: отменить её, ограничить по времени и пронести сигнал по всей цепочке вызовов.

Простыми словами: контекст — «пульт управления» для операции. Им говорят «хватит», «успей за 2 секунды» или «клиент уже ушёл». Без этого горутины легко продолжают работать впустую (утечка горутин), а HTTP/БД-запросы висят бесконечно.

## Что такое `context.Context`

Интерфейс небольшой. Важны три вещи:

- `Done() <-chan struct{}` — канал, который **закрывается**, когда работу пора остановить;
- `Err() error` — почему остановили: обычно `context.Canceled` или `context.DeadlineExceeded`;
- `Value(key)` — достать request-scoped значение (редко и осторожно).

Пока контекст жив, `Done` не закрыт. Когда отменили или вышел срок — `<-ctx.Done()` срабатывает, и код должен завершиться.

Корни дерева контекстов:

- `context.Background()` — пустой корневой контекст (`main`, старт сервера, тесты верхнего уровня);
- `context.TODO()` — «сюда потом поставим нормальный ctx», временная заглушка.

Из корня делают **дочерние** контексты. Отмена родителя отменяет детей. Ребёнок **не может** отменить родителя — контроль всегда сверху.

## Как создают контексты

`WithCancel` — ручная отмена. Удобно, когда один из воркеров уже нашёл ответ и остальным искать не нужно:

```go
ctx, cancel := context.WithCancel(context.Background())
defer cancel()

go worker(ctx)
// когда решили остановиться:
cancel()
```

`WithTimeout` — автоотмена через duration:

```go
ctx, cancel := context.WithTimeout(parent, 2*time.Second)
defer cancel()
```

`WithDeadline` — то же, но до конкретной точки во времени (`time.Now().Add(...)`). `WithTimeout` внутри как раз обёртка над deadline.

`WithValue` — положить в контекст метаданные запроса (user id, trace id). Для обычных аргументов функции это антипаттерн: значения в ctx плохо типизируются и делают зависимости неявными. На собесе правильный ответ: «только request-scoped metadata, не DI и не бизнес-параметры».

Важнейшее правило: после `WithCancel` / `WithTimeout` / `WithDeadline` **всегда** вызывай `cancel` (обычно `defer cancel()`), даже если таймаут уже сработал. Иначе можно утечь таймерами и дочерними контекстами.

## Как этим управляют выполнением

Контекст сам код не убивает. Он только **сигналит**. Ты должен слушать сигнал — обычно через `select`, как в туре с каналами:

```go
func work(ctx context.Context) error {
    for {
        select {
        case <-ctx.Done():
            return ctx.Err()
        default:
            // кусок работы
        }
    }
}
```

Или блокирующе ждать отмены рядом с другой операцией:

```go
select {
case res := <-resultCh:
    return res, nil
case <-ctx.Done():
    return nil, ctx.Err()
}
```

Идиома API: `ctx` — **первый** аргумент, имя почти всегда `ctx`. Контекст передают вниз по стеку: handler → service → repository → HTTP-клиент. Не кладут в поля struct «навсегда» и не передают `nil` (если пока нет — `TODO()`).

Типичный HTTP-пример:

```go
ctx, cancel := context.WithTimeout(r.Context(), 3*time.Second)
defer cancel()

req, err := http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
if err != nil {
    return err
}
resp, err := http.DefaultClient.Do(req)
```

Здесь важно брать именно `r.Context()`: если клиент оборвал соединение, серверный контекст тоже отменится. Если внутри хендлера создать новый `context.Background()`, связь с клиентом потеряется.

## Зачем это на собесе

Обычно ждут такой рассказ: context нужен для cancellation и deadlines в конкурентном и сетевом коде; его прокидывают первым аргументом; слушают `Done`; `cancel` всегда вызывают; `WithValue` почти не для бизнес-данных; отличие timeout и deadline; `Canceled` vs `DeadlineExceeded`.

Короткая шпаргалка:

| Инструмент            | Смысл               |
| --------------------- | ------------------- |
| `Background` / `TODO` | корень / заглушка   |
| `WithCancel`          | отменить вручную    |
| `WithTimeout`         | успеть за N времени |
| `WithDeadline`        | успеть до момента T |
| `Done` + `select`     | услышать «стоп»     |
| `defer cancel()`      | не утечь            |
