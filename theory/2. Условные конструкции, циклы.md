# Условные конструкции и циклы

В Go управляющих конструкций мало. Нет `while` и `do-while` — всё закрывает один `for`. Условия пишут через `if`/`else` и `switch`. Общее правило синтаксиса: скобки вокруг условия не нужны, а фигурные скобки обязательны.

## Цикл `for`

Классическая форма из трёх частей через точку с запятой:

```go
for i := 0; i < 10; i++ {
    sum += i
}
```

Любую часть можно опустить. Если оставить только условие — получается привычный `while`:

```go
for sum < 1000 {
    sum += sum
}
```

Если убрать всё — бесконечный цикл:

```go
for {
    // крутимся, пока не сделаем break / return
}
```

## Условие `if`

```go
if x < 0 {
    return -x
}
```

Как и у `for`, перед условием можно поставить короткий statement — часто объявление через `:=`. Переменные из него живут только внутри `if` (и связанных `else`):

```go
if v := math.Pow(x, n); v < lim {
    return v
}
```

или:

```go
if err := doSomething(); err != nil {
    return err
}
```

Переменные из short statement доступны и в `else` / `else if`. Если ветка заканчивается `return` / `break` / `continue`, лишний `else` часто не пишут — успешный путь «течёт» вниз по функции (early return).

## `switch`

`switch` — короткая запись цепочки `if-else`. Выполняется первый подходящий `case`. `break` в конце каждого `case` писать не нужно — Go сам останавливается после выбранной ветки.

Ещё отличие: `case` не обязаны быть константами, а сравниваемые значения — не обязаны быть целыми:

```go
switch time.Now().Weekday() {
case time.Saturday, time.Sunday:
    fmt.Println("выходной")
default:
    fmt.Println("будний день")
}
```

`switch` без условия — это то же самое, что `switch true`. Так удобно переписывать длинные `if` / `else if`:

```go
switch {
case t.Hour() < 12:
    fmt.Println("утро")
case t.Hour() < 17:
    fmt.Println("день")
default:
    fmt.Println("вечер")
}
```
