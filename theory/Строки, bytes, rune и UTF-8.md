# Строки, bytes, rune и UTF-8

Строка в Go — неизменяемая последовательность байт. Она не является массивом символов.

```go
s := "Привет"
fmt.Println(len(s)) // количество байт, не букв
```

Go-код обычно хранит текст в UTF-8, но значение `string` может содержать произвольные байты, включая невалидный UTF-8.

## `byte` и `rune`

```go
type byte = uint8
type rune = int32
```

`byte` представляет один байт. `rune` обычно представляет Unicode code point. Один code point в UTF-8 занимает от одного до четырёх байт.

```go
s := "AЯ"

fmt.Println(len(s))                    // 3 байта
fmt.Println(utf8.RuneCountInString(s)) // 2 rune
```

Но rune не всегда равна тому, что пользователь воспринимает как один символ. Например, буква с комбинируемым знаком или emoji может состоять из нескольких code points. Для пользовательских grapheme clusters нужны специализированные Unicode-библиотеки.

## Индексация строки

Индекс возвращает байт:

```go
s := "Я"
fmt.Printf("%x\n", s[0]) // первый байт UTF-8-представления
```

Нельзя заменить отдельный байт строки, потому что string immutable.

## `range` по строке

`range` декодирует UTF-8 и возвращает byte offset и rune:

```go
for offset, r := range "AЯ" {
    fmt.Printf("offset=%d rune=%c\n", offset, r)
}
```

Offsets будут `0` и `1`: это позиции начала rune в байтах, а не порядковые номера символов.

При невалидной UTF-8-последовательности `range` возвращает `utf8.RuneError` (`U+FFFD`) и продвигается согласно правилам декодирования.

## Преобразования

```go
bytes := []byte(s) // изменяемая копия байтов
runes := []rune(s) // декодированные code points

s1 := string(bytes)
s2 := string(runes)
```

Такие преобразования обычно создают новые данные и могут приводить к аллокациям. Не превращай строку в `[]rune`, если нужно только последовательно пройти её: `range` делает это без создания полного slice rune.

## Сборка строк

Многократная конкатенация в большом цикле может создавать много промежуточных строк:

```go
var b strings.Builder
b.Grow(estimatedSize)

for _, part := range parts {
    b.WriteString(part)
}

result := b.String()
```

`strings.Builder` предназначен для построения строки. `bytes.Buffer` удобен, когда код работает преимущественно с байтами или нужен одновременно `io.Reader`/`io.Writer`-подобный API.

## Полезные пакеты

- `strings` — поиск, разбиение, trim и builder;
- `bytes` — операции над `[]byte`;
- `unicode` — категории и свойства rune;
- `unicode/utf8` — декодирование и проверка UTF-8;
- `strconv` — числа, quoting и преобразования строк.

## Частые вопросы на собеседовании

**Чему равен `len(string)`?**  
Количеству байт.

**Что возвращает `s[i]`?**  
Байт.

**Что возвращает `range`?**  
Byte offset и декодированную rune.

**Строка всегда содержит UTF-8?**  
Нет, string может содержать любые байты.

**Как посчитать Unicode code points?**  
`utf8.RuneCountInString`, но code point не всегда равен пользовательскому символу.

**Как эффективно собрать большую строку?**  
Обычно через `strings.Builder`, желательно с `Grow`, если размер можно оценить.

**Может ли маленькая подстрока удерживать большую строку?**

Да, они могут разделять память. Если это реально создаёт проблему удержания, `strings.Clone` делает отдельную копию. Сначала проверь профиль памяти.

**`string(65)` превращает число в текст "65"?**

Нет, получится Unicode-символ `"A"`. Для десятичной записи числа нужен `strconv.Itoa(65)`.
