# Дженерики в Go

Дженерики — механизм, который позволяет переиспользовать код через параметризацию типов. Их добавили в язык в 2022 году (Go 1.18).

Дженерики полезны, когда алгоритм один и тот же для нескольких типов: например, поиск в slice. Интерфейс с методами удобнее, когда нужно подменять поведение: репозиторий, логгер или HTTP-клиент.

## Синтаксис и основные элементы

Дженерики используют три ключевых элемента:

- **формальный параметр типа** (например, `T`) — конкретный тип зависит от переданного значения;
- **ограничение типа / constraint** (например, `int | float64`) — задаёт допустимые типы для параметра;
- **фактический параметр типа** — указывается явно (`Sum[int](1, 2)`) или выводится компилятором (`Sum(3.14, 1.11)`).

С дженериками можно создавать:

- generic-срезы;
- хэш-таблицы;
- структуры;
- интерфейсы.

Пример функции сложения:

```go
func Sum[T int | float64](a, b T) T {
    return a + b
}
```

Если подходит **любой** тип, пишут constraint `any`:

```go
func Print[T any](v T) {
    fmt.Println(v)
}
```

`any` = «без ограничений» (то же, что раньше `interface{}`).

### Важно про `T any`

С `T any` внутри функции можно делать только то, что можно с **любым** типом:

- положить в переменную;
- передать дальше;
- вернуть.

**Нельзя** просто так:

- сравнивать `v == x` → нужен `comparable`;
- складывать `a + b` → нужен числовой constraint вроде `int | float64`;
- вызывать метод `v.Read(...)` → нужен интерфейсный constraint, например `io.Reader`.

## Особенности и ограничения

`~int64` допускает все типы с базовым типом int64, включая `type UserID int64`. Без `~` ограничение `int64` не включает UserID.

```go
func Contains[T comparable](items []T, target T) bool {
    for _, item := range items {
        if item == target {
            return true
        }
    }
    return false
}
```

Метод не может объявлять собственные параметры типов, но может использовать параметры generic-типа receiver. Литерал функции не объявляет type parameters, хотя может использовать `T` внешней generic-функции. Для type assertion значение сначала преобразуют в `any`: `any(v).(SomeType)`. Интерфейс с type set вроде `~int | ~int64` используется как constraint, а не как обычный тип переменной.

## Практическое применение

Чаще всего дженерики применяют для структур данных.

**Очередь** — тип элементов может быть любым (`any`). Методы вроде `Push`, `Pop`, `Peek`, `Size`.

**Куча (heap)** — элементы должны быть сравнимы/сортируемы. При инициализации часто нужен пользовательский компаратор.

**Пул объектов** — с дженериками не требуется type assertion при извлечении объекта.

## Что важно на собеседовании

Объяснить `any`, `comparable`, `~T`, вывод параметров типа и отличие generic-функции от интерфейса с методами. Знать стандартные `slices`, `maps`, `cmp`. Generics сами по себе не гарантируют ускорение: измеряй нужный сценарий benchmark. Внутреннюю специализацию компилятора можно оставить на углублённый разбор.
