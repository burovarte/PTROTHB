# Переменные, их инициализация, zero values

В Go переменная — именованное место под значение конкретного типа. Тип известен на этапе компиляции: нельзя сначала положить число, а потом строку в ту же переменную. В отличие от некоторых языков, «неинициализированных» переменных здесь нет: если объявить переменную и ничего ей не присвоить, язык сам даёт ей **zero value** — безопасное значение по умолчанию.

## Как объявляют переменные

Базовый способ — `var`. Тип пишется после имени:

```go
var i int
var s string
```

Несколько переменных одного типа можно объявить списком:

```go
var i, j int
```

Если сразу есть начальное значение, тип можно не писать — компилятор выведет его из инициализатора:

```go
var i, j int = 1, 2
var c, python, java = true, false, "no!"
```

Короткое объявление `:=` одновременно объявляет переменную и задаёт значение; тип выводится сам:

```go
k := 3
c, python, java := true, false, "no!"
```

Вне функции каждое выражение начинается с ключевого слова (`var`, `func` и так далее), поэтому конструкция `:=` недоступна.

## Константы

Константы объявляются как переменные, но с ключевым словом `const`.

Они могут быть символьными, строковыми, логическими или числовыми. Константы **нельзя** объявлять через `:=`.

```go
const Pi = 3.14
const Greeting = "hello"
```

## Базовые типы Go

```go
bool

string

int  int8  int16  int32  int64
uint uint8 uint16 uint32 uint64 uintptr

byte // псевдоним для uint8
rune // псевдоним для int32; представляет Unicode code point

float32 float64

complex64 complex128
```

Типы `int`, `uint` и `uintptr` обычно имеют ширину 32 бита на 32-битных системах и 64 бита на 64-битных. Когда нужно целочисленное значение, стоит использовать `int`, если нет конкретной причины брать тип фиксированного размера или беззнаковый тип.

## Zero values

Если объявить переменную без явного значения, она получает zero value своего типа:

```go
var i int
var f float64
var b bool
var s string

fmt.Printf("%v %v %v %q\n", i, f, b, s)
// 0 0 false ""
```

Для указателей, `slice`, `map`, `channel`, `interface` и `function` zero value — `nil`.  
У `struct` zero value — структура, у которой каждое поле само в своём zero value.  
У массива — все элементы обнулены.
