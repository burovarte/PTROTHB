# Указатели и передача данных

Опора: [Pointers](https://go.dev/tour/moretypes/1), [Pointers to structs](https://go.dev/tour/moretypes/4) в Tour of Go.

Указатель хранит **адрес** значения в памяти, а не само значение. Тип `*T` — указатель на значение типа `T`. Нулевое значение указателя — `nil` (ни на что не указывает). Разыменование `nil` → panic.

```go
var p *int

i := 42
p = &i         // & — взять адрес (address-of)
fmt.Println(*p) // * — разыменовать: прочитать значение по адресу
*p = 21         // записать значение по адресу
fmt.Println(i)  // 21
```

`&` всегда возвращает указатель (адрес). Разница в том, как `fmt.Println` это печатает: для `*int` часто виден `0xc000...`, для `*struct` — удобный вид вроде `&{1 2}`. Сам `&` в обоих случаях — адрес. Явный адрес: `fmt.Printf("%p\n", p)`.

В отличие от C, в Go **нет арифметики указателей**.

## Передача данных в функции

В Go **всё передаётся по значению** (копируется аргумент).

- передали `int` — скопировали число;
- передали `*int` — скопировали **адрес**, но оба указателя смотрят на **одни данные**.

```go
func incVal(x int)  { x++ }   // меняет копию
func incPtr(x *int) { *x++ }  // меняет оригинал

n := 10
incVal(n)    // n == 10
incPtr(&n)   // n == 11
```

Если функция ждёт `*int`, а передать `n` без `&` — ошибка компиляции (type mismatch): `int` и `*int` — разные типы. Go сам `int` в указатель не превратит.

Фраза для собеса: «Pass-by-reference как отдельного режима нет. Есть передача значения; указатель — тоже значение (адрес)».

## Указатели на структуры

```go
type Vertex struct{ X, Y int }

v := Vertex{1, 2}
p := &v
p.X = 1e9          // сахар: не нужно (*p).X
fmt.Println(v.X)   // 1000000000
```

Создать сразу указатель: `p := &Vertex{1, 2}`.

Зачем передавать `*Struct` в функцию/метод:

1. **изменить** исходную структуру;
2. **не копировать** большой struct;
3. иногда нужна семантика «значения нет» (`nil`).

Если только читаешь маленький struct — часто хватает value.

## Связка с методами

То же правило:

```go
func (v Vertex) ScaleValue(f int)  { v.X *= f } // копия
func (v *Vertex) Scale(f int)      { v.X *= f } // оригинал
```

Компилятор при вызове часто сам сделает `(&v).Scale(...)`, если `v` addressable. Для интерфейсов правила строже (method set): методы с `*T` есть у `*T`, но не у `T`.

## Когда брать указатель

Бери `*T`, если нужно менять данные снаружи, struct большой, или важен `nil`.  
Оставляй `T`, если значение маленькое, только читаешь, хочешь явную семантику «работаю с копией».

Короткая формула: «указатель = адрес; аргумент всегда копируется; скопировали адрес — можем менять общие данные через `*`».

## Shallow copy и shared state

Присваивание в Go всегда копирует значение, но некоторые значения внутри содержат указатели на общие данные. Поэтому «struct скопирован» не всегда означает «все данные независимы».

### Полностью независимые value-поля

```go
type Point struct {
    X int
    Y int
}

a := Point{X: 1, Y: 2}
b := a
b.X = 100
// a.X всё ещё 1
```

### Struct со slice

```go
type Batch struct {
    Values []int
}

a := Batch{Values: []int{1, 2, 3}}
b := a
b.Values[0] = 100

fmt.Println(a.Values[0]) // 100
```

Скопирован заголовок slice, но underlying array общий.

### Struct с map или pointer

При копировании map обе копии дескриптора обращаются к одной таблице. При копировании указателя обе копии указывают на один объект. Каналы и функции также имеют ссылочную семантику внутреннего значения.

### Интерфейс

При копировании интерфейса копируется пара «динамический тип + динамическое значение». Если внутри находится указатель, slice или map, разделяемые данные остаются общими.

### Mutex и другие sync-типы

Struct, содержащий `sync.Mutex`, `sync.RWMutex`, `sync.Once`, `sync.WaitGroup` или атомарное значение, нельзя копировать после начала использования. Копия получает отдельное служебное состояние и ломает синхронизацию. Обычно такой объект создают значением, но передают и используют через указатель на содержащую структуру.

## Deep copy

В Go нет универсального встроенного deep copy. Его делают явно согласно структуре данных:

```go
func cloneBatch(src Batch) Batch {
    dst := src
    dst.Values = append([]int(nil), src.Values...)
    return dst
}
```

Для map создают новую таблицу и копируют пары. Если значения map сами содержат slice/map/pointer, нужно решить, должны ли копироваться и они.

На собеседовании сначала уточни требуемую семантику:

- нужна независимая копия;
- допустимо совместное чтение;
- предполагается общее изменяемое состояние;
- кто владеет данными и кто может их менять.
